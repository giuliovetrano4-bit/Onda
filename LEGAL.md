# Aviso legal y método de creación

**Onda** es una aplicación original creada con [ClonaKit](https://www.divisualproject.academy), inspirada en las funciones de **Spotify**.

No contiene código, textos, imágenes, iconos, sonidos, nombres ni marcas de Spotify. Spotify es una marca de su titular; este proyecto no está afiliado a él ni cuenta con su respaldo.

## Música y servicios de terceros

Onda no aloja ni descarga música. Las canciones vienen de dos servicios externos y se usan bajo **sus condiciones**:

- **Audius** (música libre): a través de su API pública. Onda se identifica con el nombre "Onda" en cada petición y muestra el nombre del artista en cada canción. Los derechos de cada pista son de sus artistas.
- **YouTube**: la búsqueda usa YouTube Data API v3 con la clave propia de cada persona, y la reproducción usa siempre el reproductor oficial incrustado de YouTube, visible, sin tapar ni bloquear sus anuncios y sin descargar vídeos. Al usarlo se aplican las [Condiciones del servicio de YouTube](https://www.youtube.com/t/terms) y las [Condiciones de los servicios de API de YouTube](https://developers.google.com/youtube/terms/api-services-terms-of-service). YouTube es una marca de Google LLC.

## Cómo se ha creado (método de sala limpia)

1. **Investigación** (2026-11-01): se observó el funcionamiento de Spotify como usuario legítimo, con capturas de pantalla hechas con una cuenta propia, y se leyeron reseñas públicas de la app para entender qué funciones ofrece y qué echa en falta la gente. Las capturas y las notas no se publican.
2. **Especificación** (2026-11-01): se escribió una ficha funcional con palabras propias, sin copiar textos, código ni recursos.
3. **Construcción** (2026-11-01): el código se escribió desde cero tomando como única referencia esa ficha, sin acceso a la app original ni al informe de investigación.
